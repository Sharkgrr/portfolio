# Portfolio

Personal portfolio for Raphaela Oliveira, built with React + Vite. A conversational interface inspired by chat applications: sidebar navigation, suggested prompts, curated replies, and a message composer. `src/chat.css` defines the current interface over the existing base styles.

## Guided Role Fit

`src/RoleFit.jsx` renders the conversation; `src/roleFitKnowledge.js` holds the curated facts and keyword matching. Replies are not generated by AI. Unknown topics get an explicit fallback, not fabricated experience. Messages stay in React state, survive section navigation, and are cleared on reload or New conversation. No chat messages are sent to a server.

Mastra is not needed for this local guided experience. A future AI integration should use a server-side endpoint with protected credentials and grounded portfolio context, not keys in Vite client variables.

Run the matching tests with `node --test tests/roleFit.test.js`.

## Canvas and Code Parity

The code is the visual source of truth. For visual changes, update the implementation, verify desktop and mobile in the browser, then refresh the editable canvas imports from the running site. Do not maintain a separate speculative design that diverges from the implementation. Imported layers are snapshots, not automatic two-way sync. The live browser node reflects the running Vite site while the development server is available.

## Running the Frontend

```bash
npm install
npm run dev
```

Then open the URL shown by Vite.

## Backend Java

The backend is not required for the first portfolio version. The `backend/` folder provides a Spring Boot base for a future API, such as contact handling, dynamic projects, or an admin panel.

To run the backend in the future, install Java 21 and Maven, then execute:

```bash
cd backend
mvn spring-boot:run
```
